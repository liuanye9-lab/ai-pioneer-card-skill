# Brand Identity
象上汇先锋大赛 · 现代东方高级赛事卡片系统。以黑白留白为基底，以流动路径为母题，以轻交互与状态切换建立丰富体验。

# Keywords
现代东方 / 黑白灰基底 / 留白充足 / 香槟金点缀 / 流动曲线 / 水墨意象 / 向上路径 / 高级赛事感 / 低饱和 / 结构化信息 / 极简但不冷漠 / 有仪式感

# Visual Direction
现代东方美学 + 高级赛事秩序 + 轻交互卡片体验。不是传统企业海报风，不是赛博科技蓝紫风，不是高饱和年轻潮玩风。

# Emotional Tone
有节奏感、有仪式感、轻高级、不端着、不官腔，带一点赛事推进感。

# Color System
- Primary Brand (象黑): #161616
- Surface (留白米白): #F5F3EE
- Secondary Text (水墨灰): #6E706D
- Muted Text / Divider (岩灰): #CAC7C0
- Accent (鎏金): #B99A65  ← 使用比例 ≤ 10%，用于时间节点/序号/徽章/晋级标识/关键按钮描边
- Success/晋级 (低饱和橄榄绿): #7E8C6A
- Warning/倒计时 (低饱和琥珀棕): #8B5E3C
- Info (中性蓝灰): #7D8791
- Primary Text: #161616
- Elevated Surface: #FFFFFF

禁止：大面积高亮蓝紫科技渐变 / 高饱和橙荧光绿 / 五颜六色按钮 / 俗气金色光效 / 花里胡哨粒子背景。

# Typography
中文标题：思源宋体 / 方正宋体等东方气质衬线（用于「象上汇先锋大赛」等主标题）。
中文正文：思源黑体 / HarmonyOS Sans / 飞书系统无衬线。
英文辅助：全大写、小字号、增加字距（XIANGSHANGHUI / PIONEER 2026 / FINALISTS）。英文不抢中文主标题。

# Gradient
仅极弱：银灰→冷白、米白层次。禁止彩虹/霓虹/高饱和渐变。

# Radius
Small 8 / Medium 12 / Large 16 / Hero 20。

# Spacing
留白感强，不追求填满；卡片边缘与信息区要有明显呼吸空间。4/8/12/16/24/32。

# Border
线性分割线、弱边框胶囊标签；避免深色硬边框与表格感。

# Shadow
轻、扩散大、透明度低；仅用于 Hero / 重点模块。

# Icon
极简线性图标 + 数字编号；图形优先抽象（线/面/路径），不用写实插画。

# Emoji
克制使用；每模块 0-1 个。禁止 Emoji 文字化。

# Image
抽象图形母题：流动曲线（水/汇/路径/成长）、向上纵线/斜线（上升/晋级）、节点圆点（汇聚/赛程节点）、峡谷留白切面（空间感）。图形必须服务信息，不喧宾夺主。

# Illustration
现代东方抽象；水墨意象与留白切面；不做卡通大象、不做写实插画。

# Motion
慢、稳、克制、呼吸感、流动感、仪式感。一级轻动效（波纹/流线/光影/数字闪现），二级状态切换（未报名/已报名…），三级进度反馈，四级分段阅读。禁止弹跳过强/卡通过度/彩色爆闪/快速切换/低质炫光。

# Header
顶部赛事识别区：英文识别 + 中文主标题 + 卡片序号/阶段号。左对齐、纵向排列、结构清晰。

# Button
每张卡最多一个主 CTA；一张卡不超过 4 个按钮。Verb + Object。次级：查看规则/查看案例/查看回放/联系负责人。三级状态回执：我已了解/我会参加/我已提交。

# Timeline
纵向：日期 → 当前阶段 → 当前动作。鎏金用于时间节点与序号。

# Badge
弱边框胶囊标签；状态而非句子；≤ 4-6 字。

# Do
统一系列感 / 明确主次层级 / 抽象高级图形语言 / 轻互动与状态反馈 / 手机群聊可快速扫读。

# Don't
像普通通知海报 / 五彩活动 banner / 一次性塞满 / 把动效理解成复杂动画 / 依赖花哨图标和低质光效。

# 一句话风格定义
象上汇先锋大赛的飞书卡片，应是"现代东方的高级赛事卡片系统"：以黑白留白为基底，以流动路径为母题，以轻交互和状态切换建立丰富体验。
